## 1. Цели и задачи

### 1.1 Бизнес-цель
Заменить плейсхолдерные цены и контакты сайта «ЧистоДиван» на реальные данные компании: цены на химчистку диванов из официального прайс-листа (`price-list.pdf`, раздел «Мягкая мебель», ТОЛЬКО диваны) и контактные данные с основного сайта https://da-dryclean.ru/.

### 1.2 Пользовательская ценность
Посетитель нишевого сайта видит актуальные цены на диваны и реальные телефоны/мессенджеры, по которым можно сразу заказать услугу.

### 1.3 Метрики успеха
- Все цены на сайте совпадают с `price-list.pdf` (диванные позиции)
- Контакты совпадают с da-dryclean.ru
- `npm test && npm run lint && npx tsc --noEmit` — зелёные

### 1.4 Решения заказчика (вопросы Аналитика)
1. **Фокус сайта: ТОЛЬКО ДИВАНЫ.** Убрать кресла, матрасы, ковры, стулья, пуфы из калькулятора, прайса и страниц услуг. Остаётся только химчистка диванов.

## 3. Функциональные требования

### 3.1 User Stories с Acceptance Criteria

**US-1. Прайс-лист (страница /ceny)**
- GIVEN пользователь открывает /ceny WHEN страница загружена THEN отображается таблица «Химчистка диванов» с 5 типами из прайса (с размерами и ценами) и блок «Дополнительно»: спальное место 800 ₽, посадочное место 500 ₽, подушки 200/250/300 ₽, выведение запахов от 800 ₽, сильные загрязнения +20%, быстрая сушка 1 500 ₽, наценки: флок +40%, букле +50%, велюр +30%
- AND на странице НЕТ кресел, матрасов, ковров, стульев, пуфов

**US-2. Калькулятор (/#calculator)**
- GIVEN пользователь выбирает тип дивана WHEN выбран один из 5 типов THEN цена = цена типа × количество диванов (1–5)
- WHEN выбрана наценка за ткань THEN применяется ровно одна (radio-групп «Тип обивки»: Стандарт / Велюр +30% / Флок +40% / Букле +50%)

- AND в шаге выбора мебели только 5 диванных типов

**US-3. Страницы услуг (/uslugi)**
- GIVEN пользователь открывает /uslugi WHEN страница загружена THEN показаны только 2 услуги: «Химчистка дивана» (от 1 700 ₽) и «Химчистка углового дивана» (от 2 600 ₽), тексты обновлены под реальные цены
